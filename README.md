# C# ASP.NET Assignment

## Questions

### 1. Divisible by 3 and 4
Write a program that takes a number from the user then print `Yes` if that number can be divided by 3 and 4, otherwise print `No`.

### 2. Negative or Positive
Write a program that allows the user to insert an integer then print `negative` if it is a negative number, otherwise print `positive`.

### 3. Maximum and Minimum
Write a program that takes 3 integers from the user then prints the maximum element and the minimum element.

### 4. Even or Odd
Write a program that allows the user to insert an integer number then check if the number is even or odd.

### 5. Vowel or Consonant
Write a program that takes a character from the user then checks if it is a vowel character `(a, e, i, o, u)`, otherwise print `consonant`.

### 6. Numbers from 1 to N
Write a program that allows the user to insert an integer then print all numbers between 1 and that number.

### 7. Multiplication Table
Write a program that allows the user to insert a number then print its multiplication table up to 12.

### 8. Even Numbers
Write a program that allows the user to insert a number then print all even numbers between 1 and that number.

### 9. Power
Write a program that takes two integers then prints the power.

Example:
`4 3` → `64`

### 10. Marks Calculation
Write a program to enter marks of five subjects and calculate:
- Total
- Average
- Percentage

### 11. Days in Month
Write a program to input the month number and print the number of days in that month.

### 12. Simple Calculator
Write a program to create a simple calculator.

### 13. Reverse String
Write a program to allow the user to enter a string and print the reverse of it.

### 14. Reverse Integer
Write a program to allow the user to enter an integer and print the reversed number.

### 15. Prime Numbers in a Range
Write a program in C# Sharp to find prime numbers within a range of numbers.

### 16. Decimal to Binary
Write a program in C# Sharp to convert a decimal number into binary without using an array.

### 17. Three Points on a Straight Line
Create a program that asks the user to input three points `(x1, y1)`, `(x2, y2)`, and `(x3, y3)`, and determines whether these points lie on a single straight line.

### 18. Worker Efficiency
Write a program to calculate the efficiency of a worker based on the time taken to complete a specific task.

- 2 to 3 hours → Highly efficient
- 3 to 4 hours → Increase speed
- 4 to 5 hours → Training required
- More than 5 hours → Required to leave the company

### 19. Identity Matrix
Write a program that prints an identity matrix using a `for` loop. The user enters `n` and the program displays an identity matrix of size `n × n`.

### 20. Sum of Array Elements
Write a program in C# Sharp to find the sum of all elements of an array.

### 21. Merge Two Sorted Arrays
Write a program in C# Sharp to merge two arrays of the same size sorted in ascending order.

### 22. Frequency of Array Elements
Write a program in C# Sharp to count the frequency of each element of an array.

### 23. Maximum and Minimum in Array
Write a program in C# Sharp to find the maximum and minimum element in an array.

### 24. Second Largest Element
Write a program in C# Sharp to find the second largest element in an array.

### 25. Longest Distance Between Equal Cells
Given an array of integer values, find the longest distance between two equal cells.

The distance is measured by the number of cells between the two equal values.

Example:

```text
7 0 0 0 5 6 7 5 0 7 5 3
````

The longest distance is between the first `7` and the tenth `7`, which is `8` cells.

### 26. Reverse Order of Words

Given a list of space-separated words, reverse the order of the words.

Example:

```text
Input:
this is a test

Output:
test a is this
```

### 27. Copy Multidimensional Array

Write a program to create two multidimensional arrays of the same size.

Accept values from the user and store them in the first array. Copy all elements of the first array to the second array and print the second array.

### 28. Reverse One Dimensional Array

Write a program to print a one-dimensional array in reverse order.
